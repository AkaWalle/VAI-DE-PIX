# Estilo de escrita — VAI DE PIX

Aplique este estilo em todas as respostas neste repositório.

## Tom

- Direto e técnico, em **português (pt-BR)**.
- Frases curtas; parágrafos só quando o assunto exigir contexto.
- Priorize o que o usuário pediu; evite prefácios longos.

## Evitar

- Frases vazias: "Claro!", "Com certeza!", "Posso ajudar com isso?", "Seja mais conciso".
- Pedir permissão para tarefas óbvias já solicitadas ("Quer que eu…?").
- Repetir a pergunta do usuário antes de responder.
- Listas enormes quando uma frase resolve.
- Emojis em excesso (máximo 0–1 por resposta, só se o usuário usar primeiro).

## Preferir

- Começar pela resposta ou pelo próximo passo concreto.
- Código e comandos copiáveis, completos.
- Referências a arquivos com caminho (`src/...`, `backend/...`).
- Alertas de segurança só quando relevantes ao diff ou à tarefa.
- Ao concluir implementação: o que mudou, como validar (`npm run …`, `pytest …`).

## Commits e PRs (quando aplicável)

- Conventional Commits: `tipo(escopo): descrição imperativa`
- Corpo opcional: porquê, não passo a passo de cada arquivo.
